Iranian Discord

Iranian Discord is a website dedicated to helping people who use the Discord platform.

About Discord

  • Discord is a communication platform for communities and friends.
  • Users can communicate through text, voice and video.
  • Discord servers can contain multiple channels.
  • Roles and permissions help administrators manage servers.
  • Discord also supports bots, applications and integrations.

1️⃣ ساخت حساب Discord

اگر هنوز حساب نداری، ابتدا برنامه Discord را باز کن یا وارد نسخه وب شو و گزینه ثبت‌نام را انتخاب کن.

  1. روی Register / Sign Up بزن.
  2. ایمیل، نام کاربری و رمز عبور را وارد کن.
  3. تاریخ تولد را طبق اطلاعات واقعی خودت وارد کن.
  4. ثبت‌نام را کامل کن و اگر Discord ایمیل تأیید خواست، ایمیلت را تأیید کن.

2️⃣ فعال‌سازی و تأیید حساب

بعد از ساخت حساب، ممکن است Discord از تو بخواهد ایمیل یا شماره تلفن را تأیید کنی. این کار برای فعال شدن بعضی قابلیت‌ها و افزایش امنیت حساب انجام می‌شود.

  1. اگر پیام تأیید ایمیل دیدی، وارد ایمیل خودت شو.
  2. ایمیل رسمی Discord را باز کن و گزینه تأیید را بزن.
  3. اگر شماره تلفن خواسته شد، فقط شماره‌ای را وارد کن که خودت به آن دسترسی داری.
  4. اگر کپچا نمایش داده شد، مراحل آن را طبق دستور خودش انجام بده.
⚠️ کد تأیید، رمز عبور و کدهای امنیتی حساب را برای هیچ‌کس ارسال نکن.

3️⃣ فعال کردن ورود دو مرحله‌ای (2FA)

برای امنیت بیشتر می‌توانی ورود دو مرحله‌ای را از تنظیمات حساب فعال کنی.

  1. وارد User Settings شو.
  2. به بخش My Account برو.
  3. گزینه مربوط به Two-Factor Authentication را پیدا کن.
  4. مراحل نمایش‌داده‌شده توسط Discord و برنامه Authenticator را انجام بده.
  5. کدهای پشتیبان را در یک جای امن نگه دار و با کسی به اشتراک نگذار.

4️⃣ ورود به یک سرور

  1. از ستون سمت چپ روی علامت + بزن.
  2. اگر لینک دعوت داری، گزینه Join a Server را انتخاب کن.
  3. لینک دعوت را وارد کن.
  4. روی Join بزن و قوانین سرور را بخوان.

5️⃣ ساخت سرور Discord

  1. روی + در سمت چپ Discord بزن.
  2. Create My Own را انتخاب کن.
  3. نوع سرور را انتخاب کن یا گزینه مناسب را رد کن.
  4. نام و عکس سرور را تنظیم کن.
  5. روی Create بزن.

بعد از ساخت، می‌توانی کانال‌های متنی و صوتی، نقش‌ها (Roles) و دسترسی‌ها را تنظیم کنی.

6️⃣ کانال و Role چیست؟

  • Text Channel: برای پیام، فایل و گفتگو.
  • Voice Channel: برای صحبت صوتی و فعالیت‌های صوتی.
  • Role: برای تعیین نام، رنگ و سطح دسترسی اعضا.
  • در تنظیمات Permission با دقت دسترسی‌ها را بده؛ مخصوصاً دسترسی‌های مدیریتی.

7️⃣ اضافه کردن و فعال کردن بات

  1. یک بات معتبر و شناخته‌شده را انتخاب کن.
  2. صفحه دعوت (Invite) بات را باز کن.
  3. سروری را که خودت مدیریت می‌کنی انتخاب کن.
  4. مجوزهایی را که بات واقعاً لازم دارد بررسی کن.
  5. بات را وارد سرور کن و طبق راهنمای همان بات تنظیمش کن.
🔐 هیچ باتی نباید رمز عبور Discord یا کدهای ورود تو را بخواهد. قبل از Authorize کردن، نام بات و Permissionها را بررسی کن.

8️⃣ نکات مهم برای استفاده امن

  • رمز عبورت را با هیچ‌کس به اشتراک نگذار.
  • روی لینک‌های مشکوک کلیک نکن.
  • قبل از دادن Administrator یا Permissionهای حساس به یک بات، آن‌ها را بررسی کن.
  • اگر حساب یا ایمیل تأیید مشکل داشت، از پشتیبانی رسمی Discord کمک بگیر.
